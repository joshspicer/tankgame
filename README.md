# Tank Game 🎮

A multiplayer ([bluetooth](https://developer.apple.com/documentation/multipeerconnectivity)) iOS tank game, built entirely with VS Code agent mode 🚀  Built to kill time in long car rides with your siblings.

![pewpew.gif](images/pewpew.gif)

## Features

- **Real-time Multiplayer**: Connect with friends via Bluetooth using MultipeerConnectivity
- **Intuitive Controls**: Virtual joystick for movement and dedicated fire button
- **Dynamic Gameplay**: Navigate procedurally generated grids and battle it out
- **Visual Effects**: Explosive particle effects when tanks are destroyed
- **Sound Effects**: Immersive audio feedback for shooting and explosions
- **Score Tracking**: Keep track of victories in each match
