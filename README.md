A multiplayer ([bluetooth](https://developer.apple.com/documentation/multipeerconnectivity)) iOS tank game, built entirely with VS Code agent mode 🚀  Built to kill time in long car rides with your siblings.

## 🎮 Features

- **Multiplayer Combat**: 2-4 players via Bluetooth/Local Network
- **Power-up System**: 
  - ❤️ Health packs - Restore health
  - ⚡ Speed boost - Move faster temporarily
  - 🛡️ Shield - Temporary invulnerability
  - 🔥 Rapid fire - Faster shooting
- **Destructible Environment**: Brown walls can be destroyed by projectiles
- **Health System**: Each tank has 3 health points
- **Player Statistics**: Track shots fired, accuracy, and power-ups collected
- **Mini-map**: Real-time overview of the battlefield
- **Dynamic Maps**: Procedurally generated levels with varied obstacles
